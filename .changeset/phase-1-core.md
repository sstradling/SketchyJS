Phase 1: core shapes with continuous and legacy outlines, SVG path parsing and arcs, the nine built-in fills (solid, hachure, zigzag, cross-hatch, dots, dashed, zigzag-line, sunburst, starburst), scene assembly, the `RoughView` and functional `sketch` APIs, and SVG string/DOM rendering. Plugin API 1.0 includes fill regions with exact shapes, a rough-drawing kit, and a `paints` hint. The plugin conformance helpers gain input-immutability, interleaving, output-budget, and wider nondeterminism-guard checks.
